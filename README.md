# KOPI LION

Launch website and working brand foundation for KOPI LION.

## Stack
- Next.js App Router
- TypeScript
- CSS design-token system
- Three.js, loaded only when the 3D section nears the viewport
- No ecommerce or CMS in the baseline

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validate

```bash
npm run typecheck
npm run build
```

## Routes
- `/`
- `/what-is-kopi`
- `/our-roast`
- `/menu`
- `/locations`
- `/franchise`
